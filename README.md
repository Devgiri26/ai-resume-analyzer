# AI Resume Analyzer

An AI-powered resume analysis platform that helps job seekers improve their resumes by providing intelligent feedback, ATS compatibility scores, skill analysis, and actionable improvement suggestions.

Built to help candidates understand how recruiters and Applicant Tracking Systems (ATS) evaluate their resumes.

---

##  Features

###  Resume Analysis
Upload your resume and get an AI-powered evaluation of:

- Resume quality
- Structure and formatting
- Skills and experience
- Professional impact
- Missing information

###  ATS Compatibility Score

Analyze how well your resume performs against modern ATS systems.

Get insights on:

- Keyword optimization
- Job relevance
- Resume readability
- Missing skills

###  AI Feedback

Receive personalized suggestions to improve:

- Summary section
- Work experience
- Projects
- Skills
- Overall resume strength

###  Job Description Matching

Compare your resume with a target job description and understand:

- Match percentage
- Missing keywords
- Relevant skills
- Improvement areas

###  Secure Data Handling

- User authentication
- Resume management
- Secure storage
- Personal workspace
